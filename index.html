PROJ 01

Snehin Check Request Helper

~96%
processing time eliminated
3–5 min → under 10 sec per invoice
Live in Production

The Problem

Manual PDF-to-ERP data entry consumed significant staff hours per batch. No API existed. No ERP credentials available. The only path was a human typing into Business Central, field by field.

The Approach

Zero-API desktop RPA: parses vendor invoice PDFs with pdfplumber, extracts structured data, then drives the Business Central UI directly via pyautogui. No credentials, no integration.

Technical Details

Built as a desktop application with CustomTkinter for a clean user interface. Uses PyMuPDF for advanced PDF parsing alongside pdfplumber for structured data extraction. The automation layer handles dynamic field detection, error recovery, and batch processing — all without any server-side components or API keys.

PROJ 02

BC Journal Entry Bot

↑95%
reduction in processing time
Multi-source automation: PDF + Excel
Live in Production

The Problem

Journal entry processing required manually reading DocuSign PDFs and CashNet Excel files, then re-entering every debit/credit line into Business Central. Slow, error-prone, and repeated constantly.

The Approach

Automated end-to-end: reads PDF and Excel sources, structures debit/credit lines, then enters complete journal entries into Business Central via hotkey automation. No manual re-keying.

Technical Details

Combines two input sources — DocuSign PDFs (parsed with pdfplumber) and CashNet Excel exports (processed with openpyxl) — into a unified data structure. The automation then navigates Business Central's journal entry workflow, populating account codes, descriptions, and amounts for both debit and credit lines. Built with CustomTkinter for a staff-friendly UI.
