Privacy

Last updated 23 Sep 2026

This is the personal portfolio of Wasi Mahin. The short version: no cookies, no accounts, no ads, and nothing that follows you around the web. One thing does collect data — cookieless visitor analytics — and it is described below, in full. There is no contact form; reaching me means emailing me.

Rows flagged Active are the only places data about a visit is processed. All three run at Cloudflare, which hosts the site.

Analytics

This site uses Cloudflare Web Analytics. It is switched on deliberately, so I can see whether the work here reaches anyone.

It is cookieless. It does not fingerprint your device, does not build a profile of you, and cannot follow you to other websites. What it records is aggregate: page views, referring site, country, browser and device type. I can see that a page was viewed from a country. I cannot see who you are.

The data is processed by Cloudflare under the Cloudflare Privacy Policy. Blocking it changes nothing — a content blocker will stop the beacon loading and the page behaves identically.

Active
Hosting

The site is served by Cloudflare Pages. Like most hosts, Cloudflare may log visitor IP addresses and basic request data for security and operational purposes. That logging is governed by the Cloudflare Privacy Policy; I never see or store that data.

Active
Security

Cloudflare runs automated bot and abuse detection in front of this site. That is standard for any site on their network and is how it stays online. It is a security measure, not analytics, and it is not used to build a profile of you.

Active
Fonts & assets

Every font, image and script that makes up this page is self-hosted. There is no font CDN, no social widget, no advertising network and no tag manager. The only request that leaves this origin is the analytics beacon described above, and it is served by the same company that already hosts the site.
